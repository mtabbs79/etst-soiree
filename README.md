# ETST's Annual — A Very Merry Soirée (RSVP site)

RSVP site for the ETST holiday party, Friday, December 11, 2026 at Miami Springs Country Club.

- **Guests** get a personal link (`/i/<code>`). The link decides which invitation they see:
  - **Florida** — RSVP by December 1
  - **Travel** (out of state) — RSVP no later than November 16; also collects ID names, home airport, travel dates and hotel needs
- **Admins** sign in at `/admin` to see live counts, search guests, copy links, import the guest list,
  edit any RSVP (even after the deadline) and download CSVs for Excel.

## Deploy on Render
1. Push this folder to a GitHub repo.
2. In Render: **New → Blueprint**, choose the repo. It creates the web service and the Postgres database from `render.yaml`.
3. When asked, set `ADMIN_PASSWORD` (shared admin password) and `CONTACT_EMAIL` (shown to guests for questions).

## Settings (environment variables)
| Variable | Purpose | Default |
|---|---|---|
| `ADMIN_PASSWORD` | Admin sign-in password | *(required)* |
| `SESSION_SECRET` | Signs admin sessions | auto-generated by Render |
| `DATABASE_URL` | Postgres connection | wired by Render |
| `CONTACT_EMAIL` | Shown to guests | `info@etstevent.com` |
| `RESEND_API_KEY` | Turns on email sending (resend.com) | — |
| `MAIL_FROM` | Sender | `ETST's Very Merry Soirée <rsvp@etstevent.com>` |
| `MAIL_REPLY_TO` | Where guest replies go | `info@etstevent.com` |
| `BASE_URL` | Public address used in copied links, e.g. `https://party.etst.com` | the address the admin is browsing |
| `TRAVEL_DEADLINE` | Travel RSVP close (ISO time) | `2026-11-17T04:59:59Z` = Nov 16, 11:59 PM ET |
| `FLORIDA_DEADLINE` | Florida RSVP close (ISO time) | `2026-12-02T04:59:59Z` = Dec 1, 11:59 PM ET |

Event wording lives in `src/config.js`.

## Email
Admins can send invitations, reminders to people who haven't replied, and party updates from the dashboard.
Every send shows a preview first and can send a test to yourself. Each guest's invitation contains their personal RSVP link.
Resend's free plan allows 100 emails/day; use "Send at most" to split large sends across days.

## Guest list import format
Paste into the admin page (from Excel or CSV): `first name, last name, email, location`.
Location `Florida`/`FL` → Florida invite; anything else → travel invite. Every guest is invited with a plus one.

## Run locally
`npm install && DATABASE_URL=postgres://localhost/etst_soiree ADMIN_PASSWORD=secret npm start`
